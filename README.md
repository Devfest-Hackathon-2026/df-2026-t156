# WORLDSHIFT

宇宙船で荷を運ぶゲームが、「自然の中を自分の足で歩きたい」という提案から、一人称の採鉱対戦に変わりました。WORLDSHIFTでは勝者が次の遊び方を提案し、敗者は試したい案に投票します。現在のゲームは「谷の採鉱競争」。開発中の7つの大きな変化を、提案の原文と実際に遊べる39版でたどれます。

[作品サイト・57秒の実演](https://worldshift.pichu.dev/) · [宇宙船から谷への変化](https://worldshift.pichu.dev/history/#r04) · [最新版で対戦](https://worldshift.pichu.dev/play) · [次の改善案](https://worldshift.pichu.dev/history/#ideas)

## 技術構成

| 技術 | 役割・選んだ理由 |
| --- | --- |
| Unity 2022.3 / C# / WebGL | 3Dの描画・操作・手応えをUnityで作り、インストールなしでブラウザから参加できる形に。 |
| Node.js 22系 / WebSocket | 移動・採掘・命中・得点をサーバーで判定し、同じフィールドの状態を全員へ共有。 |
| Google Cloud Run | 最新版の共有対戦と、ゲーム・履歴ページ・投稿/投票APIを同じoriginで配信。参加から改善案まで一つのURLでつなぐ。 |
| Google Cloud Storage | 39版のWebGL素材を内容ごとに共通化して配信。改善案・票・試合結果に基づく投稿/投票権を、再配備後も残す。 |
| ブラウザのWeb Worker | 各版の当時のルールをブラウザ内で動かし、NPC戦として再生。旧版ごとの常設対戦サーバーを用意せず、実物を遊び比べる。 |

人が版ごとに分散せず、同じルールで競えるよう、共有対戦は最新版へ集約しています。過去の39版は一人用のNPC戦として残しています。

開発ではCodexによる実装支援と、UnitySkillsによるEditorの状態確認・操作・WebGLビルドを利用しています。実行時の対戦・旧版再生は、上表のC#・Node.js・Workerが担当します。

## 体験と改善の記録

[宇宙船から谷へ](https://worldshift.pichu.dev/history/#r04)、[背景の大岩から採掘できる近道へ](https://worldshift.pichu.dev/history/#r16)、[弓で鉱石を奪う対戦へ](https://worldshift.pichu.dev/history/#r26)。それぞれの画面から当時の版を起動できます。

過去の実例は、開発中の本人の意見をCodexが実装してきた記録です。新しい投稿・投票とは分けて表示し、自動実装・自動再配備は接続していません。

ゲーム本体は、山間の採鉱場を歩き、鉱石を掘って売り、道具へ再投資する一人称対戦です。近くで稼ぐか、希少鉱を争うか、残り時間と見える相手を読んで決めます。
## 遊び方

|操作|キー|
|---|---|
|歩く／ダッシュ|WASD／ShiftまたはW二度押し|
|忍び足／ジャンプ|C／Space|
|跳び続けて速く進む|ダッシュ中にSpace長押し|
|見回す|マウス、右ドラッグ、矢印キー|
|選んだ道具を使う|左クリック（Fでも可）、弓は長押しして離す|
|ピック／弓／袋の選択|1／2／3（ホイール・Rでも持ち替え）|
|売却／道具の強化|売店の円内で自動売却／アンビルに向けてクリック|
|測量図／カーソル解放|Tabを押している間／Esc|
|切断後の再接続|R|

画面下の3枠でピック・弓・袋と、選択中の道具を確認できます。1/2/3で選び、ホイール上下やRでも持ち替えられます。Tabで測量図を開いている間は、数字キーを行先の選択に使います。

通常鉱脈は23か所（銅8・銀6・晶6・紅晶2・ダイヤ1）。銀は南北への寄り道、晶は南北それぞれ3本、硬い紅晶は中央と左右の売店を結ぶ道の脇にあります。晶は30HPで2個・通常24点分、紅晶は48HPで2個・通常40点分。ダイヤは北寄りの一か所にあり、90HPを削ると6個・通常84点分を持ち帰れます。枯れると銅6秒・銀9秒・晶20秒・紅晶32秒・ダイヤ45秒で再生します。入りきらなかった鉱石は岩に残り、回収されるまで再生しません。打撃後に現れる白い亀裂を狙うと早く掘れます。普通に叩いても採れます。

景観の大岩14個も、その広い面を削ると銅が採れます。通常の大岩は硬さ4を削ると最初の1個、以降は8を削るごとに1個。割れた2岩は4を削るごとに1個、合計24で崩れ、同じ試合の間は通り抜けられます。崩れない岩は35秒触らないと浅い部分が戻ります。

袋は最初8個。中央・西・東のどの売店でも全鉱種を同じ通常単価で売れます。同時に一店舗だけ、軒下の吊り灯が明るく点いている間は全品約1.5倍（袋の通常総額に掛け、端数を四捨五入）。30秒ごとに店が替わります。近くで確実に売るか、灯っている店へ回るかを選んでください。先着や指定品のボーナスはありません。

売買と保護は半径4.5mの石灰線一本で示し、線上も範囲に含みます。円内へ入ると、視線・道具・ボタンに関係なく袋の鉱石をその場の価格で自動換金します。空の袋を繰り返し精算することはありません。

## 得点と強化

売却した点を使い、売店でピックを1段ずつ強化できます。代金は手持ち得点から引かれ、**3分終了時の残高**で勝敗が決まります。持ったままの鉱石は得点になりません。

|道具|その段階の購入額|採掘力（通常／亀裂）|打撃間隔|
|---|---:|---|---|
|Lv1 作業|初期装備|1／2|0.68秒|
|Lv2 鋼|8点|2／4|0.60秒|
|Lv3 超硬|12点|3／6|0.54秒|
|Lv4 鍛造|18点|4／8|0.49秒|
|Lv5 精密|24点|5／10|0.45秒|
|Lv6 貫通|32点|6／12|0.41秒|
|Lv7 重芯|44点|8／16|0.37秒|
|Lv8 極鋼|60点|10／20|0.34秒|

ピックを選び、アンビルに向けてクリックすると一段強化します。価格・採掘力・購入後残高を見て選べます。次を買うには一度離して再度クリックします。晶鉱30HPを亀裂だけで割る振り数はLv1の15打からLv4で4打、Lv7で2打へ。金の芯36HPはLv6の3打からLv8で2打になります。手元と相手のピックも刃の仕上げ・厚み・柄の帯で段階が変わります。最大までの累計投資は198点。早く掘れても投資分を売却で取り戻す必要があります。

袋は3で選び、アンビルに向けてクリックすると、8→12枠を12点、12→16枠を20点で広げられます。ピックとは別の投資で、こちらも残高から支払います。

どの道具でも全鉱種を削れます。通常価格は1個あたり銅2点・銀5点・晶12点・紅晶20点・ダイヤ14点・金28点。灯っている店では、袋の通常総額の約1.5倍になります。強化を切り上げて換金する判断にも意味があります。

金鉱は開始32秒から一か所に現れ、6秒前にその場所が分かります。現れた金は時間では消えません。取り残した鉱片も含めて採り尽くすと、次の場所が光り始めます。表層を割ると1個、続く芯を割るともう1個。1個28点を持って帰るか、2個56点まで欲張るかを選べます。表層12・芯36の硬さに対し、Lv3はLv1の3倍の力で掘れます。複数人で掘った層は、最大硬度の4分の1以上を自分で削り、最後を弱点で割り切れば回収できます。それ以外は近くに残り、袋に空きがある最大貢献者が回収し、同点なら先に貢献した人です。最後の一振りだけでは横取りできません。

対人の近接はクリックごとに判定し、届く距離は3m。人物は横に少し広く、見た目と対人の当たり判定を揃えています。有効な近接命中で、相手の袋が空でも自分が2秒間約1.4倍速く動けます。再命中は時間更新だけで重複せず、矢・採掘・空振り・無効打では加速しません。ダッシュ中の命中は強く押し返し、自分のダッシュも止まります。売店の外では相手の袋から1個奪えます。装備に関係なく、成立した一振りで1個。最後の1個も取り返せます。奪取専用の猶予はなく、通常打撃は被弾から0.5秒待つ必要があります。どちらかが売店の安全圏内にいる間は奪取できません。相手の袋の個数を見て、追う・逃げる・別の鉱脈へ向かう判断ができます。採掘は押し続けられますが、対人攻撃は押し直します。

全員が手製の弓を持っています。2で選び、使用ボタンを押して引き、狙って離すと放ちます。1秒で満引きになり、短く引くと遅く短い矢になります。満引きの初速は60m/sで、旧版の24m制限はありません。矢は重力と空気抵抗を受け、岩や鉱脈、地面で止まります。売店の円と保護中の人は通過し、奥の保護外の相手にも届きます。保護内からは撃てず、発射後に射手が保護へ入っても既に飛んでいる矢は消えません。命中すれば押し返して鉱石1個を奪えます。引いている間は移動が遅くなり、近接打撃は1のピックで行います。

## 3分と再戦

最大8人。少人数では合計3人を目安にBOTが入り、同じ道具・資源・価格で掘り、運び、強化します。試合先頭15秒は人間の目の前の銅鉱へ寄らず、人間を弓で狙いません。

終了時の順位・装備・売上・投資・残高・金の売却個数は確定し、退出で変わりません。同点は同順位。8秒後に再戦し、袋と会計、道具をリセットします。開始地点と最初に灯る店は巡回します。途中参加では、その試合の残り時間から参加します。

## ローカル起動

Unity 2022.3.22f1のWebGL Build Support、Node.js 22以上を使います。

```powershell
./Unity/Build-Web.ps1

```

[localhost:8080](http://localhost:8080/)を開きます。Webビルドは`build-web/`へ出力され、serverが同じポートで配信します。詳しい起動・配備・確認方法は[server/README](server/README.md)、Unityの作業と実試遊は[Unity/README](Unity/README.md)、通信は[protocol](protocol.md)を参照してください。

地形・鉱脈・売店・価格の正本は`Unity/Assets/Resources/valley.json`。命中、回収、奪取、売却、投資、順位はサーバーが確定します。

## 改善案と遊べる履歴

試合終了時の確定順位から、同率首位を含む人間の勝者は1件の自由記述案を投稿し、それ以外の人間は他の案に1票を入れられます。BOTには権利がなく、同じブラウザーの重複参加をまとめます。案と得票はゲーム内と `/history/` で共有され、再戦しても残ります。ブラウザーの保存データを消すと本人の権利を引き継げなくなるため、個人アカウントによる認証の代わりにはなりません。

履歴は試作から公開44までの保存された39実バージョン、46件の意見の前後関係と画面を収録しています。旧版は当時のWebGLとゲーム判定をブラウザー内のWorkerで動かし、対人オンラインは最新版のみです。過去の意見は開発中の本人入力に基づく記録で、新しい投票UIで集まった票として扱いません。AIの自動実装・本番再配備には未接続です。

`public/history/generations.json` が版と意見の正本です。世代の区切りは仮案で、既定表示は実際のバージョン順。保存を確認できない公開番号30/33/35/38/42は別記しています。履歴のソースzipはその時点のゲーム判定・共有データ等のランタイム一式で、過去のUnity C#一式ではありません。現在のUnityソース・必要素材・設定はこの公式リポジトリにあります。非公開開発Git全履歴のbundleは配布しません。

旧版の重いdata/wasmはGitに重複保存せず、SHA256付き分割資産を既存配信から復元します。ローカルで1版を遊ぶ場合は `node scripts/fetch-history-assets.mjs https://orbit-salvage-prototype-905974313870.asia-northeast1.run.app r01`、全保存版は末尾の版指定を省略します。`npm --prefix server start` 後に `/history/` へ。初回はネット接続が必要です。再生成元は `scripts/history-replay/` を参照してください。

投稿・投票のローカル保存は `FEEDBACK_FILE`、既存Cloud Runでは非公開Cloud Storageへの世代番号付き更新を使います。無設定の場合はメモリ保存になり、プロセス再起動で失われます。認証情報・実行時DB・入力例の診断ログはこのGitには含めません。
