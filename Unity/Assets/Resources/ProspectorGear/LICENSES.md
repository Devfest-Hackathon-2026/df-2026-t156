# Prospector material sources

- `Denim.jpg` is the 1K diffuse map from [Denim Fabric 04](https://polyhaven.com/a/denim_fabric_04) by Rico Cilliers and colormass.
- `Oxide.jpg` is the 1K diffuse map from [Rusty Metal 04](https://polyhaven.com/a/rusty_metal_04) by Amal Kumar.

Both maps are distributed under [CC0](https://polyhaven.com/license). Character and tool meshes are authored in ProspectorGear.cs. The ash handle uses the existing Valley/Wood texture.
