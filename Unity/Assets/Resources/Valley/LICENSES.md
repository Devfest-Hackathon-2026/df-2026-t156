# Valley natural surface sources

These original Poly Haven assets are CC0 1.0 (https://polyhaven.com/license), downloaded 2026-11-07 as 1K JPEG diffuse and OpenGL normal maps. Redistributing the source maps with this project is permitted. No live API is used in the game.

- Ground / GroundNormal: Forest Ground 04 — https://polyhaven.com/a/forest_ground_04
- Rock / RockNormal: Rock Face — Dario Barresi (processing), Greg Zaal (photography), https://polyhaven.com/a/rock_face
- Bark / BarkNormal: Bark Brown 02 — https://polyhaven.com/a/bark_brown_02
- Wood: Wood Planks Dirt — https://polyhaven.com/a/wood_planks_dirt

Terrain, rocks, trees, grass, cabin, sky shaders and meshes are authored for this project. Reference photographs were used only for observation and are not included as assets.

- Needles / NeedlesAlpha: Pine Tree 01 twig diffuse/alpha — Rico Cilliers (modeling), Rob Tuytel (photography), https://polyhaven.com/a/pine_tree_01 (CC0). Only twig texture maps are used; the large tree model is not included.
- Grass / GrassAlpha: Grass Medium 01 diffuse/alpha atlas — Rico Cilliers (modeling), Rob Tuytel (photography), https://polyhaven.com/a/grass_medium_01 (CC0). The tuft cards are authored for this project.
- Boulder.fbx / Boulder / BoulderNormal: Boulder 01 — Rico Cilliers, https://polyhaven.com/a/boulder_01 (CC0). Runtime selects supplied LOD3 (5,818 vertices). Other LOD meshes are retained in the original FBX.
- RockFace.fbx / RockFace / RockFaceNormal: Rock Face 01 — Dario Barresi, https://polyhaven.com/a/rock_face_01 (CC0). Used for cliff ledges outside the playable boundary.

All texture maps are 1K. Normal maps import as normal textures. Scanned rock models are scaled and partially embedded at the shared obstacle positions. The authoritative gameplay collision remains the conservative circular footprint in valley.json.
